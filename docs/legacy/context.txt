# CivicPulse V2.4: Project Context Report
# Date: 2026-05-05
# Version: 2.4 (Metropolitan Security Grid)

## 1. Project Overview
CivicPulse is a high-performance metropolitan security grid and infrastructure management platform. It serves as a bridge between citizens and urban authorities, utilizing AI-driven prioritization and advanced geospatial intelligence to streamline city maintenance and safety reporting.

## 2. Tech Stack (The "Pulse" Engine)
The project utilizes a modern, elite development stack designed for speed, visual excellence, and reliability.

### Frontend
- **Framework**: Next.js 15+ (App Router)
- **Language**: TypeScript (Strict typing for high reliability)
- **Styling**: Tailwind CSS 4 (Custom utility-first styling with modern tokens)
- **Animations**: Framer Motion (Sophisticated spring physics: Stiffness 400/300, Damping 30/20)
- **UI Components**: Radix UI Primitives (Ensuring accessibility and low-level UI control)
- **Maps**: Leaflet.js with React-Leaflet integration

### Backend & Infrastructure
- **Server**: Node.js (Edge-ready via Next.js API Routes)
- **ORM**: Prisma (PostgreSQL adapter)
- **Database**: PostgreSQL (Hosted on AWS/Supabase with PgBouncer)
- **Authentication**: NextAuth.js (Session-based, RBAC implementation)
- **Local Storage**: IndexedDB (via `idb` library) for offline data synchronization

### AI Layer
- **Engine**: Local Ollama Instance
- **Model**: qwen2.5-coder:7b (Optimized for coding and structured data analysis)
- **Hardware**: Dedicated inference on RTX 3050 GPU

## 3. Database Architecture (The "Grid" Schema)
The system uses a highly relational PostgreSQL schema managed through Prisma.

### Core Models
- **User**: Central identity with Role-Based Access Control (CITIZEN, AUTHORITY).
- **CitizenProfile**: Extends User with reputation points, tiers, and verification status.
- **Department**: Organizational units (e.g., PWD, TRANS) with SLA tracking.
- **Personnel**: Authority staff (Engineers, Drivers) available for assignments.
- **Report**: The central entity containing location (lat/long), AI priority scores, categories, and status lifecycles.
- **Assignment**: Tracks the lifecycle of a task from PENDING to COMPLETED.
- **PointLog**: Records gamification events (XP gains) for citizens.
- **Vote & Comment**: Social layer for community validation of reports.

### State Enums
- **Role**: CITIZEN, AUTHORITY.
- **Tier**: CITIZEN, CONTRIBUTOR, GUARDIAN, AMBASSADOR (Gamification progression).
- **Status**: OPEN, CONFIRMED, ASSIGNED, IN_PROGRESS, RESOLVED, REJECTED.
- **Category**: POTHOLES, DRAINAGE, STREETLIGHTS, SIDEWALKS, TRAFFIC_SIGNS, etc.

## 4. Key Functionalities

### A. Citizen Experience (Civic Engagement)
- **Smart Reporting**: AI-assisted prioritization (0.0 to 1.0) and automated department routing.
- **Gamification Engine**: Reputation system where users earn 25 XP per report, progressing through tiers.
- **Interactive Maps**: 500m scan radius for identifying nearby issues with dynamic clustering thresholds.
- **Offline Mode**: Local syncing of reports via IndexedDB when connectivity is low.

### B. Authority Command Center (Operations)
- **Mission Control Dashboard**: Real-time monitoring of civic health and SLA breaches.
- **Dispatch System**: Role-specific assignment (Specialist Engineer, Dispatch Driver) based on issue category.
- **AI Analytics**: Automated Ward Health Grades (A-F) generated by local LLM based on resolution metrics.
- **Resolution Workflow**: Multi-stage verification with photo-upload capability for completed tasks.

### C. Geospatial Intelligence
- **Hazard-Aware Routing**: Integration with OSRM (Open Source Routing Machine).
- **Dynamic Detours**: Triggers a 500m perpendicular detour if a navigation path intersects a 150m hazard buffer.
- **Urban Visualization**: Custom map markers with category-specific color mappings (e.g., Potholes: #FF7043).

## 5. Design System (Neon Metropolitan)
The UI follows a premium "Neon Metropolitan" aesthetic inspired by night-time Tokyo landscapes and brutalist geometric forms.

- **Palette**: Deep Urban Black (#0A0A0B), Neon Cyan (#00F3FF), Neon Magenta (#FF00E5), Electric Blue.
- **Typography**:
  - Headers: Unbounded (Bold, cinematic impact)
  - Body: IBM Plex Sans (Clarity and professionalism)
  - Technical: JetBrains Mono (For data grids and priority scores)
- **Visual Effects**: Backdrop-blur-2xl, glassmorphism, and high-contrast color accents for severity indicators.

## 6. Implementation Notes
- **AI Prompting**: Enforces strict JSON output `{"score": X.XX}` for reliable backend parsing.
- **Hybrid Filtering**: Uses server-side Prisma for text-heavy searches and client-side JS for real-time Enum filtering.
- **Reliability**: Transactional updates in Prisma ensure point logs and reports stay synchronized.
